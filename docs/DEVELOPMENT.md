# Development

## Run

```bash
npm install
npm start                    # first run: welcome window, then menu-bar only
npm start -- ~/Desktop/x.png # open an image directly
```

On first launch a short welcome window asks for **Screen Recording** permission (macOS) and shows the shortcuts.
After that OneShot starts silently in the menu bar (system tray on Windows/Linux).
In dev, macOS grants the permission to the terminal you ran `npm start` from; relaunch after allowing it.
Reset the welcome flow by deleting `~/Library/Application Support/OneShot/settings.json`, or use the menu-bar item *Welcome & Permissions…*.

## Test

```bash
npm test        # unit tests (document model, history, perspective warp), node:test, no deps
npm run smoke   # launches the real app twice (editor + capture overlay) and fails on renderer errors
npm run check   # both
```

### Debug hooks

Dev builds only. They use an isolated profile in the temp folder, so they never hand off to a running OneShot.

| Variable | Effect |
|---|---|
| `ONESHOT_DEBUG_SHOT=/path.png` | screenshot the first window after it loads |
| `ONESHOT_DEBUG_JS="…"` | run this JS in that window before the screenshot (a throw is reported) |
| `ONESHOT_DEBUG_QUIT=1` | quit after the screenshot |
| `ONESHOT_DEBUG_OVERLAY=/img.png` | open the post-capture overlay for an image |

## Build

| Command | Output in `dist/` |
|---|---|
| `npm run dist:mac` | `.dmg` + `.zip`, Apple Silicon and Intel |
| `npm run dist:win` | NSIS installer `.exe`: x64, ARM64, and one combined installer |
| `npm run dist:linux` | `.AppImage` + `.deb`, x64 |
| `npm run dist:all` | all of the above |
| `npm run dist` | current platform only |
| `npm run pack` | unpacked app for a quick local try |

Artifacts are named `OneShot-<version>-<os>-<arch>.<ext>`.
macOS can build all three platforms. Windows and Linux hosts can build their own platform (and Linux).
Local macOS builds are signed automatically if a Developer ID certificate is in the keychain (not notarized). CI builds are unsigned.
The app icon is `build/icon.png`, generated by `npm run icon`.

## Release

The version lives in `package.json` and is shown in the tray menu and the About panel.

```bash
npm run release:patch   # 0.1.0 → 0.1.1   (also :minor, :major)
```

This runs the tests, bumps the version, commits `Release vX.Y.Z`, tags `vX.Y.Z` and pushes.
The tag triggers [the Release workflow](../.github/workflows/release.yml), which builds macOS, Windows and Linux
and attaches everything to a **draft** GitHub Release. Review it on GitHub, then publish it.
Only published (non-draft, non-pre-release) releases are picked up by Appetizer.
To bump without pushing, use `npm version patch` directly.

## Default image viewer

After installing, set OneShot as the default app for images:
- **macOS:** select a PNG in Finder → Get Info → *Open with: OneShot* → **Change All…**
- **Windows:** Settings → Apps → Default apps → OneShot
- **Linux:** the `.deb` registers the image types; pick OneShot under *Open With* in your file manager.

## Code structure

```
main.js                 menu bar, shortcuts, capture, windows, IPC
preload.js              safe bridge (window.oneshot)
renderer/util.js        pure helpers (colors, clamp)
renderer/lib.js         DOM + bridge helpers shared by the pages
renderer/editor/        viewer + editor (ES modules)
  app.js                entry: history, loading, modes/tools, keyboard
  model.js              document model constants + pure helpers (tested)
  warp.js               perspective homography + bilinear warp (tested)
  state.js              shared editor state
  draw.js               painting + hit testing
  view.js               fit/zoom, canvas sizing, redraws
  pointer.js            mouse/pen interaction
  text.js               in-place text editing
  ops.js                crop/perspective/rotate/flip + export
  ui.js                 dock, popovers, inspector
  icons.js              toolbar icons
renderer/overlay.*      post-capture quick-access card
renderer/pin.*          floating pinned screenshot
renderer/launcher.*     floating capture bar
renderer/onboarding.*   first-run welcome + permission
scripts/                icon generator, smoke test, PNG encoder
test/                   unit tests
```

The editor document is a raster `base` plus vector annotations plus background settings. Annotations stay editable until export; crop shifts them, while perspective, rotate and flip burn them into the image first. Undo stores snapshots that share bitmaps rather than copying them.
